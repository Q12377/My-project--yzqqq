## 🎮 运行说明
本项目基于 Unity 2022.3.45f1c1 开发，使用了 Vuforia AR 引擎。
1. 克隆本仓库。
2. 使用 Unity 打开项目。
3. 在 Package Manager 中安装 Vuforia Engine 插件（由于 GitHub 100MB 限制，预编译包未上传）。
4. 打开 `Assets/Scenes` 下的主场景运行。
